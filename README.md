# Museum Cosplay — 빌드 배포

게임 실행 파일만 올리는 곳입니다. 소스 코드는 없습니다.

## 받기

1. 오른쪽 **Releases**에서 최신 버전을 엽니다.
2. `MuseumCosplay-<버전>.zip`을 받아 압축을 풉니다.
3. Steam을 켜 둔 상태에서 `MuseumCosplay.exe`를 실행합니다.

- Windows 64비트 전용입니다.
- 서명하지 않은 exe라서 SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"을 누르면 됩니다.
- 새 버전이 나오면 이전 폴더를 지우고 새 zip을 풀면 됩니다.
